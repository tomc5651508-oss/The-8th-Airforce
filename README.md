# The 8th Airforce

B-17E Flying Fortress squadron for the IL-2 Great Battles Normandy and Bodenplatte careers. Stock game only, no Jungle Hawks needed.

- The Pe-2 ser.35 becomes the Jungle Hawks B-17E: exterior, cockpit, 7 gun stations with crew, US bomb loads, skins, B-17E flight model figures (jhfm, B-17E only).
- Player squadron "324th Bombardment Squadron" (USA, plain olive-drab skin) in both careers: Normandy (West Malling, then Ibsley) and Bodenplatte (Chievres). Pick it in a new career (country USA); it needs the Pe-2 ser.35 (Battle of Moscow) in your account. Day level-bombing missions with stock templates, flights of 6 B-17E.
- B-17E engine sounds (VSM v7.5 Wright R-1820) in a copy of the stock sound bank.
- 22 nose art pictures as the 4th tactical-code character on both nose sides.

## Install
1. Download `The 8th Airforce <version>.zip` from Releases and unzip it anywhere.
2. Run `Install The 8th Airforce.bat`. It finds IL-2 Great Battles through Steam (or asks for the folder) and copies the mod into `MODS`.
3. Enable "The 8th Airforce" in JSGME and start a new Normandy or Bodenplatte career, country USA, 324th Bombardment Squadron.

Without the installer: copy `The 8th Airforce` into `<IL-2>\MODS` and enable it in JSGME.
A git clone needs Git LFS (`MasterBank.bank`, 111 MB, is stored with LFS).

Do not enable together with Jungle Hawks. Every Pe-2 ser.35 in the game becomes a B-17E.
